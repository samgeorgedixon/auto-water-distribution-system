# Regulated Irrigation System (RIS)

## Goals
- Water Plants
- Work in Any Environment and Scale (Greenhouse / Allotment / Farm)
- Reliable (Works for Weeks / Months)
- Sustainable (Self Sufficient: Solar / Rain)
- Relatively Cheap (< ~£100)
